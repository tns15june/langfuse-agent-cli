langfuse-agent-cli · MIT · Python 3.10+

Langfuse traces, sized for coding agents

Ask your coding agent about your LLM app in plain English. It answers from your Langfuse data with lf, a command-line tool and agent skill: failing traces with their error messages, a trace as a tree, conversations, cost, latency, prompts and scores.

Install on macOS or Linux
$ curl -fsSL https://tns15june.github.io/langfuse-agent-cli/install.sh | sh

It installs lf with uv or pipx and runs lf setup: your Langfuse keys, the agent skill, and a check. To install it yourself: uv tool install langfuse-agent-cli, then lf setup. Works with Langfuse v4, self-hosted or Cloud.

Try it

Ask in plain English

Start a new session of your coding agent and ask, for example:

  • “Why did my LLM app fail in the last hour?”
  • “Which tool fails most often this week, and since when?”
  • “What did we spend on each model this week?”
  • “Which step of my agent is the slowest?”
  • “Walk me through the conversation in session sess-42.”
  • “Which version of the welcome-bot prompt is live, and how does it read for Alice?”

How it works

From a question to a diagnosis

Coding agent

Claude Code, Codex, Cursor…

Asked “why did my app fail?”, it loads the skill on its own.

→
Skill

SKILL.md

Teaches the commands and the rules: keep output small, read before writing, never ask for keys in chat.

→
CLI

lf

Reads traces from /api/public/v2/observations, totals for cost, latency and errors from /api/public/v2/metrics, plus prompts, datasets and scores.

→
Output

Compact JSON, a tree, or a summary file

Sized for a context window, with errors and their messages up front.

Let your agent install it

One line for your coding agent

Prompt

Install langfuse-agent-cli using https://tns15june.github.io/langfuse-agent-cli/AGENTS.md

  1. The agent finds or installs lf, with the one-line installer or with uv or pipx.
  2. It runs lf setup --yes, which installs the skill for that agent and never prompts.
  3. If no keys are configured, it asks you to run lf setup in your own terminal. It never asks for keys in chat.
  4. It reports what lf doctor found and suggests a first question to try.
